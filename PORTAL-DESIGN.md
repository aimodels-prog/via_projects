# VIA client portal

The project directory (`/` and `/projects`) and client password page share the
same VIA visual system. The design references the public company website at
https://www.via-int.com/: editorial headings, white space, project-led presentation,
VIA blue and restrained red accents.

The directory hero uses the existing public company website photograph:
https://www.via-int.com/wp-content/uploads/2023/06/01-Mughsayl-Bridge-Header-Photo--scaled.jpg

It is stored locally at `src/assets/via-portal-hero.jpg` so clients do not need
to contact a third-party image server. This is a shared brand image, not a
photograph assigned to every individual project. Project cards do not expose
uploaded report photos, layouts, financial figures, briefs or progress data.

Direct project links still require the existing project password. Other projects
are displayed using the public directory fields (name, location and status).
No password checks, sessions or protected report endpoints were relaxed.
The client dashboard and PDF layouts are unchanged.
